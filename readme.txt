A lightweight, elegant Japanese A4 printable & PDF invoice and receipt system (納品書兼領収書) for WooCommerce orders.

== Description ==

WooCommerce Japanese Invoice & Receipt (納品書・領収書印刷) is a lightweight, zero-dependency WordPress plugin that generates Japanese A4 printable and PDF Invoices & Receipts for WooCommerce orders.

Fully compliant with Japan's Qualified Invoice System (インボイス制度 - 適格請求書) and equipped with dual-copy (店舗控え & お客様控え) with cut lines, dynamic logo watermarking, sticky browser print toolbars, and bulk printing.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/wc-japanese-invoice-receipt` directory, or install through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Configure your store settings under WooCommerce > Settings > 納品書・領収書.
